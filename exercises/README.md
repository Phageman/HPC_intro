## Before you start

Open a terminal: on a Mac or Linux laptop the Terminal app, on Windows Ubuntu in WSL
(install it before the workshop), on the HPC a terminal in
Open OnDemand (<https://hpcs05.op.umcutrecht.nl>). Then get the workshop files:

```bash
cd ~                          # laptop: home
cd /hpc/<group>/<user>/data   # HPC: data directory, never your home (only 7 GB)
git clone https://github.com/bayraktar1/HPC_intro.git
cd HPC_intro/exercise_data
```

All exercises start in your `HPC_intro/exercise_data`
(laptop: `~/HPC_intro/exercise_data`, HPC: `/hpc/<group>/<user>/data/HPC_intro/exercise_data`).
Not everyone needs the HPC: the exercises in part 4 say which ones work without it.

`<...>` means: fill in your own value, without the `< >`.
